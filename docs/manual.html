Jump Host · Mac 원격 제어

Jump 사용 설명서

집에 있는 Mac(예: Mac Studio)을 밖에서 MacBook, 아이폰, 아이패드, 안드로이드 폰으로 조작하는 앱입니다. Mac에 한 번 설치해 두면, 다른 기기에서는 주소를 열고 비밀번호만 넣으면 됩니다. 복사·붙여넣기가 기기 사이에 오가고, 모니터가 여러 대면 골라 볼 수 있고, 연결이 잠깐 끊겨도 알아서 다시 붙습니다.

화면과 소리, 입력, 복사한 글자는 Mac과 접속 기기가 직접 주고받고, 암호화되어 있습니다. 집 밖에서 접속하려면 두 기기가 서로를 찾도록 이어 주는 중개 서버가 필요합니다. 내 Cloudflare 무료 계정에 한 번 만들어 두면 됩니다(아래 "밖에서 접속 준비"). 이 중개 서버는 내 Mac만 쓸 수 있게 잠겨 있고, 공유기 설정이나 VPN은 필요 없습니다.

Mac에 설치 처음 한 번

준비: Apple 칩(M1 이상) Mac, macOS 14 Sonoma 이상. 받은 JumpHost-버전.zip 파일.

  1. 압축을 풀고 응용 프로그램 폴더로 옮기기

    zip을 더블클릭하면 폴더가 생깁니다. 안의 JumpHost를 Finder 왼쪽의 응용 프로그램으로 끌어다 놓으세요.

  2. 처음 열기 (한 번만 허용)

    App Store 앱이 아니라서 처음에는 "열 수 없음" 창이 뜹니다. 완료를 누른 뒤 아래 순서로 허용하세요.

    • 시스템 설정 → 개인정보 보호 및 보안에서 맨 아래까지 내립니다.
    • "JumpHost이(가) 차단되었습니다" 옆의 그래도 열기를 누르고, Mac 암호를 입력합니다.

    이 버튼이 안 보이면 터미널에서 xattr -dr com.apple.quarantine /Applications/JumpHost.app을 실행한 뒤 다시 여세요.

  3. 권한 두 개 켜기

    처음 실행하면 권한을 요청합니다. 시스템 설정 → 개인정보 보호 및 보안에서 아래 두 곳의 JumpHost를 켜세요.

    • 화면 및 시스템 오디오 녹음: 화면과 소리를 보냅니다. 켠 뒤 "종료 후 다시 열기"가 뜨면 누르세요.
    • 손쉬운 사용: 마우스와 키보드를 조작합니다.
  4. 메뉴바 아이콘 확인

    화면 맨 위 오른쪽에 모니터 모양 아이콘이 생깁니다. 누르면 아래 메뉴가 나옵니다. 권한 두 줄에 허용됨 ✓이 보이면 집 안에서는 바로 쓸 수 있습니다.

    예시 화면입니다. 주소와 비밀번호는 Mac마다 다릅니다. "어디서나 접속" 링크는 다음 단계에서 중개 서버를 만들면 생깁니다. 그 전에는 "꺼짐"으로 보입니다.

    아이콘이 안 보이면 카메라 노치 뒤에 숨은 것입니다. ⌘ Space로 Spotlight를 열고 JumpHost를 실행하면 같은 메뉴가 마우스 위치에 뜹니다.

  5. 꺼지지 않게 설정
    • 메뉴의 로그인 시 자동 실행 · 멈추면 다시 켜기는 처음부터 켜져 있습니다. Mac을 재시동하거나 Jump가 오류로 멈춰도 알아서 다시 켜집니다. 처음 한 번 "백그라운드 항목이 추가됨" 알림이 뜰 수 있습니다. 메뉴에 "허용이 필요합니다"가 보이면 눌러서 JumpHost를 켜 주세요.
    • 시스템 설정 → 에너지(노트북은 배터리 → 옵션)에서 디스플레이가 꺼졌을 때 자동 잠자기 방지를 켜세요. Mac이 잠자기에 들어가면 밖에서 접속할 수 없습니다.
    • Mac Studio라면 같은 화면의 정전 후 자동으로 시동도 켜 두면 좋습니다.

    모니터 화면은 꺼져도 괜찮습니다. 접속하면 Jump가 화면을 깨웁니다.

주의 · Mac Studio에 모니터가 아예 연결되어 있지 않으면 보낼 화면이 없습니다. 모니터를 연결해 두거나(대기 상태 괜찮음), 모니터 없이 쓰려면 HDMI 더미 플러그를 꽂아 두세요. 재시동 직후 FileVault 잠금 화면은 원격으로 풀 수 없으니, 정전이나 업데이트 후에는 집에서 한 번 로그인해야 합니다.

밖에서 접속 준비 중개 서버 · 처음 한 번, 10분

집 밖에서 접속하려면 내 Cloudflare 무료 계정에 작은 중개 서버를 하나 만듭니다. zip 안의 중개 서버 만들기 폴더에 있는 스크립트가 알아서 만들고 Jump에 연결해 줍니다. 만들어진 중개 서버는 이 Mac만 쓸 수 있게 잠깁니다.

  1. Node.js 설치

    nodejs.org에서 LTS 버전의 macOS 설치 프로그램(.pkg)을 받아 설치합니다. 스크립트가 쓰는 도구입니다.

  2. Cloudflare 무료 가입

    dash.cloudflare.com/sign-up에서 이메일로 가입하고 메일 인증까지 마칩니다. 브라우저는 로그인된 채로 두세요. 결제 정보는 필요 없습니다.

  3. 스크립트 실행

    Jump Host가 켜진 상태에서 중개 서버 만들기 폴더의 중개 서버 만들기.command를 더블클릭합니다. 터미널 창이 열리고 순서대로 진행됩니다.

    • 처음에 "열 수 없음"이 뜨면 앱 때와 같이 개인정보 보호 및 보안 → 그래도 열기를 누르세요. 또는 터미널에 bash (뒤에 한 칸)를 치고 파일을 끌어다 놓은 뒤 Enter를 눌러도 됩니다.
    • 브라우저가 열리면 Cloudflare 로그인 후 Allow를 누릅니다.
    • workers.dev 이름을 물으면 영어 소문자로 원하는 이름을 넣습니다(처음 한 번만 묻습니다).
  4. 링크 확인

    "✓ 완료"와 함께 https://jump-relay.내이름.workers.dev/#id=… 링크가 나오고 클립보드에 복사됩니다. Jump 메뉴에도 어디서나 접속 (중개 서버 연결됨)과 이 링크가 생깁니다. 접속할 기기로 보내 두세요.

무료 플랜으로 충분합니다. 영상은 중개 서버를 거치지 않고 기기끼리 직접 오갑니다.

접속하기

Jump 메뉴의 어디서나 접속 링크와 비밀번호만 있으면 어디서든 접속할 수 있습니다. 집 Wi‑Fi에서는 메뉴의 접속 주소(http://192.168…:47866)도 됩니다.

MacBook · PC 추천: Chrome

MacBook · PC

  1. Chrome에서 주소를 엽니다.
  2. 비밀번호를 넣고 연결을 누릅니다.
  3. 툴바의 ⛶전체화면을 누르면 ⌘W 같은 단축키도 Mac으로 갑니다.

회사 PC처럼 여럿이 쓰는 컴퓨터에서는 이 기기에 비밀번호 기억이 꺼진 채로 시작합니다. 창을 닫으면 비밀번호를 잊어서, 나중에 그 브라우저를 쓰는 사람이 들어올 수 없습니다. 내 폰·아이패드·Mac에서는 켜져 있습니다.

윈도우 PC에서는 Ctrl이 Mac의 ⌘로 바뀌어 전달됩니다(Ctrl+C·V·A 그대로 사용, 윈도우 키는 Mac의 Control). ⚙ 설정의 Ctrl을 ⌘처럼에서 끌 수 있고, 안드로이드 앱에 키보드를 연결했을 때도 같습니다. 키보드의 한/영 키를 누르면 Mac의 입력 언어가 한국어 ↔ 영어로 바뀝니다.

전체화면은 Esc를 길게 누르면 빠져나옵니다. 전체화면이 아닐 때나 Safari에서는 ⌘W·⌘T·⌘Q를 브라우저가 먼저 가져갑니다. 집 Wi‑Fi 주소(http)로 접속했을 때도 그렇습니다.

홈 화면 앱으로

아이폰 · 아이패드

  1. Safari에서 주소를 엽니다.
  2. 공유 버튼 → 홈 화면에 추가를 누릅니다.
  3. 홈 화면의 Jump 아이콘으로 열면 주소창 없이 전체 화면으로 쓸 수 있습니다.

새 버전이 나오면 다음에 열 때 자동으로 바뀝니다.

앱 또는 Chrome

안드로이드

  1. 받은 Jump-버전-android.apk를 설치합니다. "출처를 알 수 없는 앱" 허용이 필요합니다.
  2. 앱의 Mac 주소 또는 링크 칸에 "어디서나 접속" 링크를 붙여 넣고 비밀번호를 넣습니다.

앱 없이 Chrome에서 주소를 열어도 됩니다. 앱에는 화면 회전 고정 기능이 더 있습니다.

한 번에 한 기기만 연결되고, 다른 기기가 접속하면 먼저 연결된 기기는 끊깁니다. 와이파이↔LTE 전환처럼 연결이 잠깐 끊기면 화면에 "다시 연결하는 중…"이 뜨고 1분 정도 알아서 다시 붙습니다.

조작법

MacBook · PC (마우스, 트랙패드, 키보드)

평소처럼 쓰면 됩니다. 커서는 Mac 쪽 모양(화살표, 텍스트 커서 등)으로 보이고, 클릭·오른쪽 클릭·스크롤·키보드 입력이 그대로 Mac으로 갑니다. 한/영 전환은 Mac에서 쓰던 키(Caps Lock 등) 그대로, PC 키보드는 한/영 키로 됩니다. 그래도 안 되면 Mac 화면 메뉴바의 입력 메뉴에서 바꾸세요.

복사 · 붙여넣기

하고 싶은 것방법
Mac에서 복사 → 이 기기Mac에서 복사하면 이 기기에도 복사됩니다. 아이폰·아이패드 등은 다음에 화면을 한 번 탭할 때 들어오고, "📋 Mac에서 복사한 내용을 가져왔습니다"가 뜹니다.
이 기기에서 복사 → Mac키보드로 ⌘V(윈도우·안드로이드는 CtrlV)를 누르면 이 기기에서 복사한 글자가 Mac에 붙여집니다. 키보드가 없으면 ⌨ 키보드를 열고 거기에 붙여넣기 하세요.

글자만 오갑니다(그림·파일 제외). 끄려면 ⚙ 설정의 클립보드 공유나 Mac 메뉴의 클립보드 공유를 끄세요.

크롬 원격 데스크톱과 같은 두 가지 방식이 있습니다. 툴바의 👆바로 클릭 버튼(브라우저에서는 ⚙ 설정 → 화면 터치에서도)으로 바꾸고, 고른 방식은 기억됩니다.

화면 키보드 (아이폰 · 아이패드 · 안드로이드)

툴바의 ⌨키보드를 누르면 화면 키보드와 그 위에 입력 막대가 뜹니다. 막대 왼쪽의 바로 | 입력창으로 입력 방식을 고르고, 고른 방식은 다음에도 기억됩니다.

방식이렇게 동작합니다
바로치는 대로 Mac의 커서 위치에 바로 입력됩니다(크롬 원격 데스크톱처럼). 막대에 esc · tab · 화살표 · ⌫ · ⏎ 키가 있고, 안드로이드 앱에는 ⌘ ⌃ ⌥ ⇧ 조합키도 있습니다.
입력창막대의 입력창에 먼저 쓰고(자동완성·수정 자유, 여러 줄 가능) 전송을 누르면 Mac의 커서 위치에 한 번에 들어갑니다. 줄바꿈은 줄바꿈 그대로 들어가고, 옆의 ⏎는 Mac에서 Enter를 누릅니다. ✕는 방금 전송한 글을 Mac에서 지웁니다(한 번 더 누르면 그 전 것도). Mac 화면을 누르면 커서가 옮겨질 수 있어 ✕는 꺼집니다. 채팅창에 긴 글을 쓸 때 편합니다.

키보드가 올라오면 Mac 화면 전체가 키보드 위 남은 공간에 보이고(채움은 키보드를 내리면 돌아옴), 툴바와 스틱이 남은 공간에 맞춰 작아지거나 아이콘만 남아서 가로 화면에서도 버튼이 가려지지 않습니다.

아이패드에 키보드를 연결했다면 ⌨를 열지 않아도 그대로 칩니다. ⌨를 연 상태로 연결한 키보드를 쳐도 글자가 두 번 들어가거나 깨지지 않도록, 연결한 키보드의 키는 Mac으로 키 그대로 보내고 한글 조합은 Mac이 합니다. 한/영 전환은 툴바의 한/A한/영 버튼이나 키보드의 한/영 키로 합니다.

포인팅 스틱 (화면 구석의 투명한 원)

손가락으로 화면을 가리지 않고 커서를 정밀하게 움직일 때 씁니다. MacBook 트랙패드처럼 천천히 밀면 조금, 빠르게 밀면 멀리 갑니다.

툴바 버튼

가로 화면에서는 스틱 반대편 끝에 세로 한 줄로, 세로 화면에서는 위쪽 끝에 가로 한 줄로 반투명하게 붙어 있습니다. 한 줄에 다 들어가지 않으면 버튼이 작아지고 아이콘만 남습니다.

툴바를 0.5초 길게 누르면 파란 테두리가 생기고 손가락을 따라옵니다. 놓으면 가장 가까운 위 · 아래 · 왼쪽 · 오른쪽 끝에 한 줄로 붙습니다.

  • 옆에 붙이면 세로 한 줄, 위나 아래에 붙이면 가로 한 줄입니다. 키보드가 올라와 너무 좁을 때만 두 줄로 나뉘고, 숨는 버튼은 없습니다.
  • 스틱이 있는 쪽에 붙이면 스틱이 반대편으로 비켜납니다. 스틱을 직접 옮겨 둔 경우에는 툴바가 스틱을 피해서 놓입니다.
  • 길게 눌렀다가 움직이지 않고 놓으면 자동 위치로 돌아갑니다.

안드로이드 앱에는 화면 회전(자동·가로·세로) 버튼과, 확대했을 때 나오는 원래 크기 버튼이 더 있습니다.

설정과 비밀번호

하고 싶은 것방법
비밀번호 바꾸기 (밖에서)접속한 기기에서 ⚙ 설정 → Mac 비밀번호 변경. 현재 비밀번호가 필요합니다. 눈 모양 버튼을 누르면 입력한 글자가 보입니다.
비밀번호 바꾸기 (Mac에서)메뉴 → 비밀번호 직접 설정…(8자 이상) 또는 비밀번호 새로 만들기(무작위)
화면이 끊길 때메뉴 → 화질 → 절약 (최대 1600px). 집 인터넷이 느리거나 LTE일 때 부드러워집니다.
소리를 Mac에서만툴바 🔊 버튼으로 Mac 재생을 고르거나, 메뉴의 소리 전송을 끄세요.

비밀번호를 바꿔도 지금 연결은 유지되고, 다음 접속부터 새 비밀번호를 씁니다. 접속한 기기는 새 비밀번호를 기억합니다.

문제 해결

접속이 안 돼요 ("Mac에 연결할 수 없습니다" 등)
  • "Mac이 꺼져 있거나 인터넷에 연결돼 있지 않습니다"가 뜨면 Mac이 잠자기 상태이거나 JumpHost가 꺼져 있습니다. 집에서 메뉴의 "어디서나 접속"이 연결됨인지 확인하세요.
  • 설치 5단계의 잠자기 방지와 로그인 시 자동 실행을 켜 두면 다시 생기지 않습니다.
  • 링크 끝의 #id=…가 잘리지 않았는지 확인하세요.
  • Mac 메뉴에 "등록 정보가 중개 서버와 다릅니다"나 "중개 서버가 이 Mac을 받지 않습니다"가 보이면(설정을 지웠거나 다시 설치한 경우) 중개 서버 만들기.command를 한 번 더 실행하세요. 이 Mac을 다시 등록합니다.
  • 메뉴에 "중개 서버의 화면이 이 Mac과 다른 버전"이 보이면 역시 중개 서버 만들기.command를 다시 실행하면 됩니다.
"비밀번호가 틀렸습니다" / "시도 횟수 초과"

1분 안에 5번 틀리면 그 기기(인터넷 주소)만 1분 동안 잠깁니다. 또 틀리면 2분, 4분… 최대 1시간까지 늘어나고, 한 번 맞히면 풀립니다. 다른 사람이 비밀번호를 맞혀 보더라도 내 기기는 잠기지 않습니다. 비밀번호는 Mac 메뉴에서 ⌥를 누른 채 보면 보입니다.

중개 서버 만들기 스크립트가 멈추거나 실패해요
  • "Node.js가 필요합니다": 열린 페이지에서 LTS 설치 후 다시 실행하세요.
  • "Jump Host를 먼저 한 번 실행하세요": 메뉴바 아이콘이 생긴 뒤 다시 실행하세요.
  • 로그인에서 멈추면 브라우저에서 dash.cloudflare.com에 로그인한 뒤 다시 실행하세요. 여러 번 실행해도 괜찮습니다.
화면이 검게 나오거나 "화면을 캡처할 수 없습니다"
  • 메뉴에서 화면 기록 권한이 허용됨인지 보세요. 켜져 있는데도 안 되면 목록에서 JumpHost를 − 로 지우고 + 로 다시 추가한 뒤 앱을 다시 여세요.
  • 모니터가 연결되어 있는지 확인하세요 (설치 섹션의 주의 참고).
클릭이나 키보드가 안 먹어요

메뉴에서 손쉬운 사용 권한을 확인하세요. 허용됨인데도 안 되면 목록에서 지우고 다시 추가하세요.

Mac 잠금 화면이 보여요

화면이 꺼진 뒤 잠기도록 설정되어 있으면 잠금 화면이 보입니다. 접속한 기기에서 Mac 로그인 암호를 입력해 보세요. 입력이 안 되면 집에서 시스템 설정 → 잠금 화면의 "화면 보호기 시작 또는 디스플레이가 꺼진 후 암호 요구" 시간을 길게 바꾸세요.

화면이 뚝뚝 끊기거나 흐려요
  • 메뉴 → 화질 → 절약으로 바꾸세요.
  • 집 Mac은 가능하면 유선 랜이 좋습니다.
  • ⚙ 설정 → 통계 표시를 켜면 속도(Mbps)와 지연(RTT)이 보입니다. RTT가 150ms 이상이면 네트워크 문제입니다.
소리가 안 나요

툴바의 🔊 버튼이 이 기기 재생(아이폰 재생, 폰 재생 등)인지 확인하세요. 아이폰·아이패드는 무음 스위치와 볼륨도 확인하세요. Mac 메뉴의 소리 전송이 켜져 있어야 합니다.

회사망에서 안 돼요

회사망이 기기끼리 직접 연결(UDP)을 막으면 화면 연결 단계에서 멈출 수 있습니다. 이때는 중개 서버에 우회 경로(Cloudflare TURN, 월 1,000GB 무료)를 켜야 합니다. 중개 서버 만들기 폴더의 set-turn-secrets.sh가 그 설정을 하니, 앱을 준 사람에게 도움을 받으세요. 회사가 workers.dev 주소 자체를 막으면 휴대폰 핫스팟으로 접속하세요.

업데이트

  1. Mac 메뉴에서 종료를 누릅니다.

  2. 새 zip을 풀고 JumpHost를 응용 프로그램에 덮어씁니다(대치).

  3. JumpHost를 다시 엽니다. 권한과 비밀번호, 링크는 그대로 유지됩니다. 메뉴 아래쪽에서 버전을 확인할 수 있습니다.

  4. 새 zip의 중개 서버 만들기.command도 한 번 더 실행합니다. 접속 화면이 새 버전으로 바뀝니다(이미 로그인되어 있어 1분이면 끝납니다).

아이폰·아이패드·브라우저 쪽은 자동으로 새 버전이 적용됩니다. 안드로이드 앱은 새 APK를 덮어서 설치하세요.

보안

  • 링크와 비밀번호를 가진 사람은 Mac을 조작할 수 있습니다. 둘을 함께 남에게 보내지 마세요. 의심되면 비밀번호를 바꾸세요.
  • 비밀번호는 8자 이상으로 쓰세요. 짧으면 Mac 메뉴와 접속 화면에 경고가 뜹니다.
  • 여럿이 쓰는 컴퓨터에서는 이 기기에 비밀번호 기억을 끈 채로 쓰세요(기본값).
  • 비밀번호는 로그인할 때 네트워크로 보내지 않고 확인 값만 주고받습니다. 화면·소리·입력·복사한 글자는 기기와 Mac 사이에서 암호화됩니다.
  • 중개 서버는 내 Mac만 등록할 수 있게 잠겨 있고, 비밀번호나 화면은 중개 서버를 지나가지 않습니다.
  • 공용 와이파이에서는 192.168… 주소 대신 "어디서나 접속" 링크(https)를 쓰세요. 같은 와이파이의 다른 웹사이트가 이 Mac에 접속을 시도하는 것은 막혀 있습니다.
  • 원격으로 비밀번호를 바꿀 때도 암호화된 연결로만 보내고, 현재 비밀번호를 다시 확인합니다.
